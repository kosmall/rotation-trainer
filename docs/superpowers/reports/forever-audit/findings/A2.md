# A2: spells and stats (audit findings)

Auditor: A2. Files: `src/forever/data/spells.json`, `src/forever/spells.ts`, `src/forever/stats.ts`,
`src/forever/data/levels.json`, `src/forever/data/classic_base.json`, `src/forever/data/params.json`,
`src/forever/types.ts`. Source of truth: `docs/forever-data-ledger.md` (typed into the scripts independently of the data files).
No repository file was changed except this one. Reproduction scripts (scratchpad, `/tmp/claude-0/-home-user-rotation-trainer/05276e97-9c03-5b59-93ad-fdb2660cdf40/scratchpad/`):
`a2_ledger_vs_spells.py`, `a2_probe.ts`, `a2_swing13.ts`, `a2_regen_scale.ts`, `a2_mob_hp_vs_median.py`.

Summary: no numeric spell rank contradicts a confirmed ledger entry. The findings are (a) unflagged Classic assumptions
hard-coded in `stats.ts` and `params.json`, (b) generator artifacts in the `classic_base.json` mob table (negative mob damage at level 13,
HP overshoot at levels 57-60), (c) missing or stale `verify` flags, (d) hard-coded talent constants that duplicate `talents.json`.
